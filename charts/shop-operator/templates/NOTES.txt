Shop, Wallet and DiscordChannel CRDs (shophub.io/v1alpha1).

  kubectl get deploy -n {{ .Release.Namespace }} {{ include "shop-operator.fullname" . }}
  kubectl get shop,wallet,dch -n {{ .Values.shopsNamespace }}

Only Shops and Wallets in namespace {{ .Values.shopsNamespace }} are reconciled; DiscordChannels
also in {{ .Release.Namespace }} (platform alerts channel). Each Shop is served at
https://<shop>.{{ .Values.shopDomain }} through IngressClass {{ .Values.ingressClassName }}.

Discord is not configured: DiscordChannels will report DiscordCredentialsMissing. Set
discord.guildID and create Secret {{ .Values.discord.tokenSecretName }} (key "token") in
{{ .Release.Namespace }} — see the shop-operator README.
{{- end }}

CRDs are kept on uninstall (helm.sh/resource-policy: keep) so Shops are never deleted by
removing the chart.
